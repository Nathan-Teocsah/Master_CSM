# Comment faire ?

1. Ouvrir un terminal dans le fichier où on a téléchargé le Makefile
2. écrire dans le terminal : make
3. attendre
4. aller dans son Dossier personnel (correspondant au "HOME" du système)
5. normalement un dossier Environnement_virtuel est créé


# Comment lancer jupyterlab ?
## Methode 1
1. clic droit sur start.sh et cliquer sur "Executer comme un programme" 
2. normalement cela lance jupyter dans le moteur de recherche par défaut

## Methode 2
1. ouvrir une invite de commande dans Environement_virtuel
2. taper : start.sh
3. normalement cela lance jupyter dans le moteur de recherche par défaut
