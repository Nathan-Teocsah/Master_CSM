# (Classification (ou régression)) Classification de cancer à partir de données ARN

Le séquençage du génome a permis de grandes avancées médicales ces dernières années. En particulier, on peut aujourd'hui utiliser des séquences d'ARN pour identifier la présence d'un cancer.

L'objectif de ce projet est de proposer et comparer des méthodes de machine learning pour classer différents types de cancers à partir d'expression de gènes. Nous travaillons sur un jeu de données extrait  de la base synapse  et qui porte sur 5 types de tumeurs.

Il y a deux fichiers, un qui contient les expressions de gène (20531 variables pour 801 individus) et l'autre qui contient le type de cancer associé à chacun 801 individu (ligne du premier tableau).
